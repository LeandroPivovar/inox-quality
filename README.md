# Inox Quality - site institucional

Site one-page da **Inox Quality** ("Onde o aço vira inspiração"): projetos em aço inox sob medida em Itajaí - SC e região.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato com mapa, FAQ)
styles.css   # estilos (preto e amarelo do logo, tons de aço, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, marca, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.
